# 谷子账本 · 简洁版

直播间谷子的**储值记账小工具**。只记一件事：**某位顾客的余额加了多少、减了多少。**

单个 HTML 页面，零依赖、零构建、零服务器；手机浏览器打开即用，也可以托管到 GitHub Pages。

## 为什么是「简洁版」

直播时手忙脚乱，填不完商品名、制品类型、寄售价这些细节。所以这一版**只有金额加减**：

- 每位顾客有两个按钮：**加钱（+）/ 减钱（−）**
- 点开只需要填一个金额，备注可以留空
- 时间和经手人默认用「现在」和默认经手人，收在折叠区里；要补记昨天的账再展开改

顾客抽到谷子寄售、卖出后回款，都用「加钱」记一笔、备注写「吧唧卖出」即可——数一样算得对，但操作只要三秒。

## 账目口径

```
当前余额 = Σ 加钱 − Σ 减钱
```

例子：

| 日期 | 事件 | 金额 | 余额 |
|---|---|---|---|
| 10-10 | 存入 | +30 | 30 |
| 10-11 | 抽到一个吧唧 | −15 | 15 |
| 10-11 | 吧唧放直播间卖 8 元 | 0 | 15 |
| 10-12 | 吧唧卖出 | +8 | **23** |

界面上会直接显示成算式 `+30 −15 +8 = 23`，余额怎么来的不用口算。

## 功能

- **首页**：合计未兑付余额（总共欠顾客多少）、每位顾客余额、按最近/余额/名称排序、搜索（名称 / 手机号 / 备注）
- **顾客详情**：
  - 顶部一条**账目算式**，如 `+30 −15 +8 = 23`
  - 累计加钱 / 累计减钱 / 记账笔数
  - 明细时间轴，可按日 / 月 / 年分组，每行显示这笔发生后的余额
  - 底部两个大按钮：**加钱 / 减钱**
- **报表**：今日 / 本月 / 今年 / 全部；未兑付余额、净变动、加钱、减钱；**每日对账表**（期初 → 每日净变动 → 期末）
- **删除**：
  - 删客户：详情页右上角 `⋮` → 删除这位客户（连同他的记账一起删）
  - 删单笔：点开那条记录 → 删除；记错了但想留痕就选「作废」
  - 清空全部：设置 → 危险操作 → 清空（二次确认）
- **设置**：直播间名称、默认经手人、JSON 备份与恢复、CSV 导出

> 所有确认框都是页面自己的弹层，不依赖浏览器 `window.confirm()`——内嵌浏览器里原生弹窗会被拦截，导致「点了没反应」。

## 怎么打开

**方式一（最简单）**：双击 `index.html`，浏览器直接打开。

**方式二（本地服务）**：

```bash
python -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765/
```

**方式三（给别人用）**：把整个目录传到 GitHub 仓库，Settings → Pages → Deploy from a branch → main / root，2 分钟后得到 `https://<用户名>.github.io/<仓库名>/`，手机打开后「添加到主屏幕」即可。

第一次打开是空的，可以先点「载入示例数据看看效果」，熟悉后在设置里清空。

## 数据在哪、会不会丢

**数据存在浏览器本地（localStorage），不上传服务器。** 这样不需要服务器、断网也能记账。代价是：

- 换手机、换浏览器、清理浏览器数据 → 看不到旧账
- **多台设备之间不会自动同步**

所以请每天收播后点一次「设置 → 备份数据 → 导出」，把 JSON 存到微信文件传输助手或网盘；需要换设备时在新设备上「导入」即可完整还原。首页超过 7 天没备份会自动提醒。

## 本地开发

```bash
# 计算层单元测试
node --test test/core.test.js

# 截图 / 交互验证（需要本机有 Edge 或 Chrome）
node tools/shoot.js "http://127.0.0.1:8765/index.html?demo=1" shots/home.png --w 390 --h 844
```

## 文件结构

```
index.html            入口，唯一页面（hash 路由）
assets/core.js        纯计算：金额、余额、算式、分组、每日对账、CSV（有单元测试）
assets/store.js       localStorage 持久化、增删改查、导入导出、示例数据
assets/app.js         界面与交互（含应用内确认框）
assets/style.css      样式
test/core.test.js     18 项单元测试
tools/shoot.js        无头浏览器截图 / 交互验证工具
```

金额一律以「分」为整数存储计算（不会有 0.1+0.2 的浮点误差）；时间以本地字符串 `YYYY-MM-DDTHH:mm` 存储（不涉及时区换算）。老版本数据（带寄售、商品类型的那种）导入后会自动简化成加钱/减钱，金额不变。
