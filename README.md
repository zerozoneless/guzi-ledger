# 谷子账本 · 简洁版

直播间谷子的**储值记账小工具**。只记一件事：**某位顾客的余额加了多少、减了多少。**

单个网页，零依赖、零构建；手机浏览器打开即用。支持**免费云同步**——2～3 个人用不同手机记同一本账，数据不丢。

## 两种用法

| | 单机版 | 云同步版 |
|---|---|---|
| 配置 | 什么都不用做 | 填三个参数（见下文） |
| 数据位置 | 你这台手机的浏览器里 | Supabase 免费数据库 + 本机缓存 |
| 多人共用 | ❌ 各记各的 | ✅ 同一本账 |
| 换手机 | 要手动导出/导入 | 重新填配置即可 |
| 成本 | 0 | 0（Supabase 免费额度） |

**没配置就是单机版**，随时可以在设置里开启同步，本地已有的数据会自动上传，不会丢。

## 账目口径

```
当前余额 = Σ 加钱 − Σ 减钱
```

| 日期 | 事件 | 金额 | 余额 |
|---|---|---|---|
| 10-10 | 存入 | +30 | 30 |
| 10-11 | 抽到一个吧唧 | −15 | 15 |
| 10-11 | 吧唧放直播间卖 8 元 | 0 | 15 |
| 10-12 | 吧唧卖出 | +8 | **23** |

界面直接显示成算式 `+30 −15 +8 = 23`。

## 功能

- **首页**：合计未兑付余额、每位顾客余额、按最近/余额/名称排序、搜索
- **顾客详情**：账目算式、累计加钱/减钱/笔数、按日/月/年分组的明细（每行带该笔发生后的余额）、底部两个大按钮「加钱 / 减钱」
- **记账**：只填金额，备注可留空，时间默认现在（要补记再展开）
- **报表**：今日/本月/今年/全部；未兑付余额、净变动、加钱、减钱；**每日对账表**（期初 → 每日净变动 → 期末）
- **删除**：删客户、删单笔、作废、清空全部（都有二次确认）
- **备份**：JSON 导出/导入、CSV 导出

## 开启云同步（免费，约 5 分钟）

1. 打开 [supabase.com](https://supabase.com) 注册（邮箱即可，**不用信用卡**），新建一个 project。区域选 Singapore 或 Tokyo 都行。
2. 左侧 **SQL Editor → New query**，把本仓库 `supabase-setup.sql` 整段粘进去，**先把两处 `guzi-2026` 改成你自己的房间码**，然后 Run。
3. 左侧 **Project Settings → API**，复制这两个值：
   - `Project URL`（形如 `https://abcdefgh.supabase.co`）
   - `anon public` key（一长串 `eyJ...`）
4. 打开 App → **设置 → 云同步 → 设置**，填入：项目地址、anon key、房间码（要和 SQL 里改的一致），保存。
5. 其他人用同样三个值配置一次，就能看到同一本账了。

**注意事项**

- 免费额度：500MB 数据库 + 5GB 流量。这本账一年也就几 MB，够用很久。
- 免费项目连续 **7 天完全没人访问**会被自动暂停；直播间每天都在用，不会触发。真被暂停了，去控制台点 Restore 即可，数据还在。
- **房间码就是密码**，别外传。万一泄露，在 SQL 里改成新的、所有人重填一次。
- 同步按「后写覆盖」合并（每条记录带毫秒时间戳）。两人同时改同一条，晚改的生效；新增记录不会互相覆盖。
- 删除是「打墓碑」而不是物理删除，所以另一台手机同步后不会把删掉的数据又推回来。

### 不想注册？先本地试

仓库里带了一个假的 Supabase，可以在自己电脑上验证同步流程：

```bash
node tools/mock-supabase.js 54321
# App → 设置 → 云同步 → 设置，填：
#   项目地址：http://127.0.0.1:54321
#   anon key：mock
#   房间码：r1
```

## 怎么打开

- **本机**：双击 `index.html`
- **本地服务**：`python -m http.server 8765` → `http://127.0.0.1:8765/`
- **给直播间用**：把整个目录传到任意静态托管（GitHub Pages / Vercel / Cloudflare Pages / 腾讯云静态托管），手机打开后「添加到主屏幕」，图标和 App 一样

> GitHub Pages 在国内偶尔不稳；要求稳可以用国内静态托管。网页本身不需要备案，但**云同步的 Supabase 域名在境外**，网络特别差时同步会慢，数据仍在本地不会丢。

## 数据安全

- 数据双份：本机 localStorage + 云端（开启同步时）
- 任何一次同步失败都不会丢数据，只是暂时没传上去
- 设置里有「导出 JSON」做冷备份，超 7 天没备份首页会提醒

## 文件结构

```
index.html               入口（hash 路由）
assets/core.js           纯计算：金额、余额、算式、分组、每日对账（有单元测试）
assets/store.js          localStorage、增删改查、墓碑、导入导出
assets/cloud.js          云同步：Supabase REST、合并策略
assets/app.js            界面与交互（含应用内确认框）
assets/style.css         样式
supabase-setup.sql       云同步建表脚本
test/                    单元测试
tools/shoot.js           无头浏览器截图/交互验证
tools/mock-supabase.js   本地假 Supabase
mini/                    微信小程序版本（备用，未使用）
```

金额一律以「分」为整数计算（没有浮点误差）；时间以本地字符串 `YYYY-MM-DDTHH:mm` 存储（不涉及时区换算）。

## 关于小程序版本

`mini/` 里是一套完整的微信小程序实现（页面 + 云函数），原本计划用「小程序 + 云开发」。但云开发没有长期免费额度（基础套餐约 ¥20/月），所以目前主线用网页版 + 免费云同步。

如果以后愿意出这 20 元：注册小程序 AppID → 开通云开发 → 建 4 个集合（members / customers / txns / meta，权限设为「仅管理端可读写」）→ 上传 `cloudfunctions/ledger` 云函数 → 用微信开发者工具导入 `mini/` 即可运行，记账逻辑与网页版一致。
